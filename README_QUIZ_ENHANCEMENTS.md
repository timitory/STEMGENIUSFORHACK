## 💡 Pro Tips for Using

### Excel Upload
1. Download the template from the app
2. Keep format: Q | 4 Options | Answer (1-4) | Points
3. Use 1-4 for correct answer (not 0-3)
4. Points column is optional (defaults to 10)

### AI Generation
1. Be specific with topic (e.g., "Photosynthesis in Plants")
2. Start with 5 questions to test quality
3. Mix difficulties for balanced quiz
4. Can regenerate if unsatisfied

### Input Styling
1. All inputs now have gradient backgrounds
2. Focus ring changes with state (blue/red/green)
3. Works perfectly in dark mode
4. Mobile responsive and accessible
