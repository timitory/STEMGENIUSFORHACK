## 🎨 Color & Design System

### **Live Quiz Color Palette:**

```
Primary Gradient: Purple → Pink
┌─────────────┐
│  #9333EA    │  Deep Purple (Create Quiz)
│    ↓↓↓      │
│  #EC4899    │  Bright Pink
└─────────────┘

Secondary Gradient: Blue → Cyan
┌─────────────┐
│  #2563EB    │  Blue (Join Quiz)
│    ↓↓↓      │
│  #06B6D4    │  Cyan
└─────────────┘

Accent Colors:
✅ Green (#10B981) - Correct answer
❌ Red (#EF4444) - Wrong answer
⏳ Gray (#9CA3AF) - Neutral/Other
🏆 Gold (#FBBF24) - Rankings
```

### **Button Styles:**

```
Primary (Create/Join):
  Background: Gradient (Purple→Pink or Blue→Cyan)
  Color: White text
  Border Radius: 12px
  Padding: 16px 24px
  Font Weight: Bold

Secondary (Actions):
  Background: Transparent with border
  Color: Text color
  Hover: Background tint
  Border: 2px solid

Disabled State:
  Opacity: 50%
  Cursor: Not allowed
  Hover: None
```

## 📐 Layout Specifications

### **Card Sizes:**

```
Desktop:
- Live Quiz card: Full width main section
- Create/Join buttons: 48% width each (split grid)
- Max width: 1280px

Tablet (iPad):
- Live Quiz card: Full width with padding
- Create/Join buttons: 48% width each
- Max width: 900px

Mobile:
- Live Quiz card: Full width with padding
- Create/Join buttons: Stack vertically (100% width)
- Max width: Full screen - 16px padding
```

### **Spacing:**

```
Section Gap: 32px (2rem)
Card Padding: 24px (1.5rem)
Button Padding: 16px vertical, 24px horizontal
Icon Size: 16-24px
Border Radius: 12px (cards), 8px (inputs)
```

## ✨ Interactive States

### **Button States:**

```
Default:
  Background: Gradient
  Shadow: None
  
Hover:
  Background: Gradient (lighter)
  Shadow: 0 10px 25px rgba(0,0,0,0.1)
  Scale: 1.02x
  
Active/Click:
  Shadow: Inset
  Scale: 0.98x

Disabled:
  Opacity: 50%
  Cursor: Not allowed
  No hover effects
```

### **Input Field States:**

```
Normal:
  Border: 2px solid #E5E7EB
  Background: White
  
Focus:
  Border: 2px solid #9333EA (Purple)
  Background: #F3E8FF (Light purple)
  Outline: None
  
Error:
  Border: 2px solid #EF4444 (Red)
  Background: #FEE2E2 (Light red)
  Icon: ❌ Red X
  Message: "Error message" in red
```
